# Shooter — 3D FPS 팀 데스매치

브라우저에서 2명 이상이 방을 만들어 팀을 나누어 싸우는 3D 1인칭 슈팅 게임입니다.

## 기술 스택
- **서버**: Node.js + Express + Socket.IO (서버 인증식 물리/사격 판정)
- **클라이언트**: Three.js (WebGL)
- 테스트: `node scripts/test-game.js` (코어), `node scripts/test-socket.js` (통합)

## 실행 방법
```bash
npm install
npm start          # http://localhost:3000
```

## 라이브 배포
- **플레이 URL**: https://shooter-mfal.onrender.com/
- GitHub push 시 Render가 자동 재배포됩니다 (`render.yaml`)
- Free 티어라 15분 무접속 시 절전 → 첫 접속이 ~30초 느릴 수 있음
서버 외부 접속 시:
```bash
$env:PORT=3000; npm start        # (PowerShell)
```
방 코드를 친구에게 공유하면 같은 방에 참여할 수 있습니다.

## 게임 규칙
- 두 팀(레드/블루)으로 자동 분배, 최소 2명이면 시작 가능
- 상대를 **20킬** 먼저 하거나, 4분이 지나 점수가 높은 팀이 승리
- 전사하면 3초 후 자신의 팀 스폰 지점에서 부활
- 무기: **SMG(1) / AR(2) / Sniper(3)** — 탄창 소모 시 자동/수동(R) 재장전
- 머리(head)를 맞추면 데미지 1.5배 → 헤드샷

## 조작법
| 플랫폼 | 키/조작 |
|---|---|
| PC | WASD 이동 · Shift 달리기 · 마우스 조준(클릭) · LMB(유지) 사격 · R 재장전 · 1/2/3 무기 |
| 모바일 | 왼쪽 가상 조이스틱 이동 · 오른쪽 드래그 조준 · 🔫 발사 · ↻ 재장전 · ⚔️ 무기 전환 |

## 구조
```
server/game.js      게임 엔진 — 맵/충돌/이동/히트스캔 사격/스코어 (순수 로직, 테스트 가능)
server/server.js    Socket.IO 방 관리 + 30Hz 게임 루프 + 15Hz 상태 브로드캐스트
client/index.html   로비/HUD/오버레이 UI
client/main.js      Three.js 씬 · 조준 · 입력 전송 · 리모트 보간
scripts/            단위/통합 테스트
```

## 네트워크 설계 (요약)
- **서버 인증식**: 30Hz 물리 틱이 모든 이동·사격을 판정하고 15Hz로 스냅샷을 브로드캐스트
- 클라이언트는 **입력(키/조준/발사)만 전송**, 서버가 위치를 계산해 되돌려줌
- 근거리(my LAN/같은 네트워크)에서는 부드러운 보간으로 자연스럽게 플레이 가능
- 벽 · 스폰 포인트 · 무기 밸런스는 `server/game.js`의 `MAP`/`WEAPONS`에서 조정
